Gemini 생성 연결

연결된 Gemini 서버로 상세 컷 계획과 실제 스케치 이미지를 생성합니다.

서버 요청은 하루 이미지 30회·계획 30회까지입니다. 실패한 요청도 포함됩니다.

키는 이 페이지의 메모리에서만 사용하며, 새로고침하면 사라집니다. 요청은 Google API로 직접 전송됩니다.

선택한 모델이 연결 계정에서 지원되어야 합니다. 서버 이용 권한과 결제 상태에 따라 생성 가능 여부가 달라집니다.

Google AI Studio에서 키 발급

처음 사용하는 분을 위한 가이드

“만든 사람 입장에서 보는 것이 아니라, 처음 보는 사람이 편하게 이해할 수 있도록 설계해야 한다.”

  1. 기존 Gemini 서버가 기본 연결됩니다. 본인 키를 사용하려면 API 연결에서 연결 방식을 바꿉니다.
  2. 이야기와 컷 수, 화면 비율, 스케치 스타일을 선택합니다.
  3. 참고 이미지를 넣으면 동일한 인물·의상 유지의 기준이 됩니다.
  4. 스토리보드 만들기를 누르면 컷 계획 후 이미지를 순서대로 생성합니다.
  5. 프롬프트를 복사하거나 PNG·HTML로 다운로드하세요. PDF 버튼은 인쇄 창에서 PDF로 저장을 선택하면 됩니다.

실패한 이미지 컷은 개별 재시도로 복구할 수 있습니다. 생성 결과는 자동 저장되지 않으므로 페이지를 닫기 전에 다운로드하세요.
