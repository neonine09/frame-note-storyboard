# 프레임노트

프롬프트를 상세 스토리보드 계획과 실제 AI 스케치 이미지로 만드는 한글 웹 도구입니다.

## 사용

1. 기존 Gemini 서버가 기본 연결되어 있어 별도 키 입력 없이 시작합니다.
2. 이야기, 3/6/9컷, 화면 비율, 스케치 스타일을 선택합니다.
3. 필요하면 인물 참고 이미지와 고정 설정을 추가합니다.
4. 상세 계획을 만든 뒤 각 컷 스케치를 순서대로 생성합니다.
5. PNG 콘티, 개별 이미지, 오프라인 HTML 또는 인쇄 PDF로 보관합니다.

기본 연결은 기존 Cloudflare 서버의 Gemini Secret을 사용합니다. 키는 브라우저나 GitHub에 공개하지 않습니다. 서버 전체 하루 한도는 계획 30회, 이미지 30회이며 실패 요청도 포함합니다. API 연결에서 본인 키 모드로 전환할 수도 있으며, 본인 키는 메모리에만 보관하고 Google API로 직접 전송합니다. 요금·모델 이용 권한은 연결된 Google 프로젝트 기준입니다. GitHub Pages는 정적 페이지를 호스팅하며 이미지 모델을 자체 실행하지 않습니다.

사용 가능 모델은 계정과 모델 수명주기에 따라 달라집니다. 이미지 모델은 API 연결에서 변경할 수 있습니다. 실제 API 연결 없이 샘플 이미지나 템플릿을 생성 결과로 표시하지 않습니다.

## 로컬 실행

HTTP 정적 서버에서 프로젝트 루트를 제공합니다. 예: `python -m http.server 4175`. 별도 빌드나 패키지 설치는 필요하지 않습니다.

## GitHub Pages

저장소 Settings → Pages → Deploy from a branch → main / (root)를 선택합니다.

## 설계 기준

만든 사람 입장에서 보는 것이 아니라, 처음 보는 사람이 편하게 이해할 수 있도록 설계해야 한다.

각 컷 10초, 첫 3초 훅, 액트/씬/컷 구조, 인물·의상·배경 일관성, 매끄러운 카메라 이동, 자연스러운 대사, 영문 프롬프트와 한글 번역을 반영합니다. AI 결과는 정확성·연속성을 사람이 검토해야 합니다.
